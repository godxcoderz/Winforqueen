# WinForQueen

A royal fantasy action game about a wandering prince, a fearless princess, and a kingdom worth protecting. Explore a colourful storybook world, face stronger guardians, and fight your way through ten chapters.

## Features

- Ten chapters with increasing enemy difficulty
- Browser-based side-view action gameplay
- Three special moves: **Moon Cut**, **Starfall**, and **Royal Step**
- Keyboard and mobile touch controls
- Synthesized sound effects
- Local player name, score, and progress saving
- Responsive layout for desktop and mobile screens

## Controls

| Action | Keyboard |
| --- | --- |
| Move | Left / Right arrows |
| Jump | Space |
| Moon Cut | J |
| Starfall | K |
| Royal Step | L |
| Basic attack | X |

On mobile, use the on-screen buttons.

## Run the game

Open `index.html` in a modern browser. An internet connection is needed to load the optional Google Fonts; the gameplay itself uses local HTML, CSS, and JavaScript files.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**, then save.
4. Wait for GitHub Pages to publish the site.

A workflow is also included under `.github/workflows/deploy.yml` for automated deployment.

## Project note

WinForQueen is an independent fan-inspired fantasy project. It is not affiliated with or endorsed by any existing anime or television franchise. The characters and scenery in this prototype are original CSS/canvas illustrations rather than imported character art.
